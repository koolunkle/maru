# Proposal

## Why

11/7~11/8 시연에서 세 페르소나(docs/PRODUCT.md 2절)의 흐름을 끊김 없이 보여 줘야 한다. 연속 출석·난이도 변화·주간 리포트는 며칠치 기록이 있어야 보이고, 우체통·릴레이는 다른 사람의 글이 있어야 보인다. 기존 ROADMAP의 T13을 옮긴 것이다.

## What Changes

- 7일치 기록이 있는 데모 계정을 만든다(릴레이·편지·가구 포함).
- 시연 전에 받을 글을 준비한다: 보조 계정으로 우체통 글과 같은 카테고리 릴레이 글(7일 이내)을 보내 검수를 통과시킨다.
- 지은 흐름용 계정의 구에 이번 주 행사가 있는지 확인한다(행사가 많은 종로구·중구 권장).
- 운영 URL에서 온보딩 → 추천 → 인증 → 릴레이 → 편지 → 휴게소 흐름을 웹과 휴대폰(Expo Go)에서 끝까지 진행한다.
- 시연 모드(댓글·릴레이 공개 1분)를 켜고, 시연 뒤 끈다.
- 피드에 저작권 문제가 될 이미지가 없는지 확인하고 테스트 데이터를 정리한다.

하지 않는 것: 앱 동작 변경. 리허설에서 찾은 문제는 GitHub Issue로 남기고 각각 따로 고친다.

## Capabilities

### New Capabilities

없음.

### Modified Capabilities

없음. 동작 변경이 없는 운영 준비 작업이라 `skip_specs: true`로 둔다.

## Impact

- 운영 DB에 데모·보조 계정과 그 기록이 생긴다. 시연 뒤 보조 계정은 지운다.
- `app_config`의 시연 모드를 켰다 끈다(`select public.set_demo_mode(true|false);`).
- 코드·마이그레이션·함수 배포 없음.
