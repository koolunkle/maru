## ADDED Requirements

### Requirement: 무거운 날이 이어질 때 도움 안내
앱은 오늘을 포함한 최근 3일(KST) 동안 매일 "마음이 무거워요"를 기록했으면 기록 화면(S7)에 안내 카드와 휴게소의 도움받을 수 있는 곳으로 가는 버튼을 보여 줘야 한다(SHALL). 안내에는 진단·판정 문구와 금칙어를 쓰지 않는다.

#### Scenario: 사흘 연속
- **GIVEN** 그저께, 어제, 오늘 모두 "마음이 무거워요"를 기록했다
- **WHEN** 기록 화면을 연다
- **THEN** 안내 카드가 보이고 버튼을 누르면 휴게소로 간다

#### Scenario: 하루가 비었을 때
- **GIVEN** 그저께와 오늘은 "마음이 무거워요"이고 어제는 기록이 없다
- **WHEN** 기록 화면을 연다
- **THEN** 안내 카드는 보이지 않는다

#### Scenario: 다른 기분이 섞였을 때
- **GIVEN** 최근 3일 중 하루가 "조금 무거워요"다
- **WHEN** 기록 화면을 연다
- **THEN** 안내 카드는 보이지 않는다
