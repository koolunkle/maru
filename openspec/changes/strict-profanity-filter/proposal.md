# Proposal

## Why

익명 응원 공간에서 욕설·비방을 받은 사용자는 다시 글을 쓰거나 피드를 열지 않게 된다. 지금 공통 검수는 욕설·비방 판정을 AI 한 번에만 맡겨 변형 욕설(`ㅅㅂ`, `시1발`, `씨 발`)과 비꼼·조롱을 놓칠 수 있다. 다른 사람의 글로 다시 위축되지 않아야 하는 고립·은둔 전 단계 청년(docs/PRODUCT.md 1.2절, 페르소나 민수·예진)을 위해 다른 사람에게 보일 글의 욕설·비방을 더 엄격하게 막는다.

## What Changes

- AI 검수 전에 글을 정규화(전각·호환 문자 통일, 공백·특수문자·숫자 끼워넣기 제거, 자음·모음 분리 결합)한 뒤 욕설 사전과 대조한다. 명백한 욕설이 있으면 AI를 부르지 않고 바로 거절한다.
- 변형 욕설(초성 `ㅅㅂ`, 숫자 끼우기 `시1발`, 띄어쓰기 `씨 발`, 특수문자 끼우기 `시.발`)도 같은 욕설로 본다.
- 욕설과 겹치는 일상어(`시발점`, `자살골`, `수박씨 발라`처럼)는 허용 목록으로 걸러 오탐을 피한다.
- 위기 표현은 계속 다른 기준보다 우선한다. 글에 위기 표현이 있으면 규칙 단계에서 거절하지 않고 AI 판정으로 넘겨, 욕설이 섞여 있어도 작성자가 도움 안내를 받게 한다.
- AI 분류 기준의 거절 범위를 넓힌다: 특정인·집단을 향한 조롱·비꼼·인신공격, 외모·능력·나이·성별·지역 등을 이유로 한 비하, 혐오 표현. 판단이 애매하면 거절한다.
- AI를 쓸 수 없을 때도 규칙으로 걸린 욕설은 거절한다. 규칙에 걸리지 않은 글은 지금처럼 검수 대기로 남는다.
- 적용 범위는 공통 검수를 쓰는 피드 댓글(F6), 응원 릴레이(F10), 마음 우체통(F14) 모두다.
- 거절 시 작성자 안내 문구는 댓글·릴레이의 기존 문구를 그대로 쓴다(댓글 "이 댓글은 공개되지 않았어요"). 마음 우체통의 거절 문구는 연락처만 언급해 욕설 거절과 맞지 않으므로 "이 한 줄은 전달되지 않았어요. 누구나 편하게 읽을 수 있는 말로 다시 적어볼까요?"로 바꾼다.

**하지 않는 것**
- 신고·차단 기능, 이미 공개된 글의 사후 숨김.
- 작성 중 실시간 경고나 앱(클라이언트) 쪽 입력 차단. 판정은 서버에서만 한다.
- 위기 키워드의 규칙 판정(AI 없이 crisis로 분류). 위기 판정은 지금처럼 AI가 한다.
- 거절 사유(욕설·연락처·비방)를 작성자에게 구분해 알리는 문구.
- 이미 공개된 기존 글의 재검수.

## Capabilities

### New Capabilities

없음.

### Modified Capabilities

- `mailbox`: 거절 상태 안내 문구를 바꾼다.
- `content-moderation`: 거절 분류에 비방 범위(조롱·비꼼·인신공격·비하)와 "애매하면 거절"을 더하고, AI 전에 욕설을 규칙으로 거절하는 요구사항과 AI를 쓸 수 없을 때의 규칙 거절을 추가한다.

## Impact

- 코드: `supabase/functions/_shared/moderation.ts`(규칙 단계·AI 기준 문구), 새 `_shared/moderation-profanity.ts`(정규화·욕설 사전·허용 목록), `tests/relay.test.mjs`·`tests/mailbox.test.mjs` 또는 새 테스트 파일.
- Edge Function 재배포: `_shared/`가 바뀌므로 `moderate-comment`, `mailbox`를 다시 배포한다(사람이 요청할 때만).
- DB 마이그레이션: 없음. 판정 주체 값 `rule`이 응답에 새로 나올 수 있으나 저장 컬럼은 바뀌지 않는다.
- 운영 설정값(app_config): 변경 없음.
- 앱 코드: `src/lib/mailbox.ts`의 우체통 거절 문구만 바뀐다. 거절 응답 처리는 기존과 같다.
