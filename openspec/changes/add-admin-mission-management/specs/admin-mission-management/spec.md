## ADDED Requirements

### Requirement: 비밀번호로 관리자 접근
관리 화면은 외부 웹에서 관리자 비밀번호로 접근할 수 있어야 한다(SHALL). 모든 관리 요청은 서버에서 권한을 검사해야 하며, 비밀번호는 URL·앱 저장소·앱 번들에 남기지 않아야 한다(MUST). 반복된 잘못된 입력은 일정 시간 제한한다.

#### Scenario: 올바른 비밀번호
- **WHEN** 올바른 관리자 비밀번호를 입력한다
- **THEN** 미션 관리 화면에 접근한다

#### Scenario: 잘못된 비밀번호 또는 비밀번호 없음
- **WHEN** 비밀번호가 없거나 올바르지 않은 관리 요청을 보낸다
- **THEN** 미션과 사진을 조회하거나 변경할 수 없다

#### Scenario: 반복 입력
- **WHEN** 짧은 시간 안에 잘못된 비밀번호를 반복해서 제출한다
- **THEN** 일정 시간 입력을 제한하고 재시도를 안내한다

### Requirement: 미션 내용과 추천 기간 관리
관리자는 미션을 검색하고 페이지별로 조회하며 제목·카테고리·난이도·시간·인증 힌트·추천 기간을 등록하거나 수정할 수 있어야 한다(SHALL). 잘못된 값은 저장하지 않으며 사용자 기록이 연결된 미션은 삭제하지 않는다.

#### Scenario: 새 미션 등록
- **WHEN** 관리자가 유효한 미션 정보를 저장한다
- **THEN** 현재 Maru DB에 미션이 등록되고 기준 사진을 연결할 수 있다

#### Scenario: 잘못된 기간
- **WHEN** 종료일이 시작일보다 앞선다
- **THEN** 저장하지 않고 날짜를 확인하도록 안내한다

#### Scenario: 기존 사용자 기록 보존
- **WHEN** 사용자 활동이 연결된 미션을 삭제하려 한다
- **THEN** 삭제하지 않고 기존 기록을 유지한다

### Requirement: 비공개 기준 사진 관리
관리자는 미션별 JPEG·PNG·WebP 기준 사진을 최대 4장, 각 2 MiB 이하로 등록하고 비교 힌트를 보존하며 조회·삭제할 수 있어야 한다(SHALL). 일반 사용자는 관리 경로로 사진에 접근할 수 없다. 사진 등록의 일부 단계가 실패하면 이미 저장한 사진은 보존하며 고아 파일을 남기지 않도록 처리한다.

#### Scenario: 사진 등록
- **WHEN** 관리자가 미션에 유효한 사진과 힌트를 등록한다
- **THEN** 해당 미션의 인증에서만 비교에 사용한다

#### Scenario: 사진 제한 위반
- **WHEN** 개수·용량·형식 제한을 넘는 사진을 등록한다
- **THEN** 저장하지 않고 제한을 안내한다

#### Scenario: 저장 또는 삭제 오류
- **WHEN** 관리 요청 중 저장소나 DB 요청이 실패한다
- **THEN** 성공으로 표시하지 않고 재시도를 안내하며 기존 데이터를 보존한다
