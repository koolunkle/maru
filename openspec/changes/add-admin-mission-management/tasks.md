## 1. 서버

- [ ] 비밀번호 검사·반복 입력 제한·서버 전용 권한과 접근 정책을 구현한다.
- [ ] 미션 검색·등록·수정·보호된 삭제를 구현한다.
- [ ] 기준 사진의 안전한 등록·조회·삭제와 힌트 보존을 구현한다.
- [ ] 필요한 마이그레이션을 작성하고 검증하며 DB 타입을 재생성한다.

## 2. 관리자 웹

- [ ] /admin에서 비밀번호 입력과 미션·추천 기간·기준 사진 관리를 제공한다.
- [ ] 기존 Maru 컴포넌트·토큰을 재사용하고 문서를 갱신한다.

## 3. 검증

- [ ] 미인증·비밀번호 오류·반복 입력 제한·입력 검증·사진 제한·기존 기록 보존·저장 오류를 테스트한다.
- [ ] npm run typecheck, npm run lint, npm test, npm run spec:validate를 실행한다.
- [ ] 미리보기에서 관리자 흐름을 확인하고 실제 사진은 사용자 등록 이후 검증한다.
