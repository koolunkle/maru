## 1. 데이터셋

- [ ] 1.1 현재 Maru DB 공용 미션에서 장소가 정해진 미션 3~5개를 고르고 id를 기록한다.
- [ ] 1.2 미션마다 기준 사진 2~4장과 제출 사진 10장 안팎을 모은다(design.md 표). 사용 권한과 얼굴·번호판 노출을 확인한다.
- [ ] 1.3 이 폴더에 `dataset.json`(파일 이름, 미션 id, 종류, 기대 결과, 출처)을 만든다. 사진 파일은 올리지 않는다.

## 2. 평가 스크립트

- [ ] 2.1 `verify-mission`을 불러와 가짜 DB·Storage와 실제 AI 호출로 판정하는 평가 스크립트를 이 폴더에 만든다(design.md).
- [ ] 2.2 사진 2~3장으로 먼저 돌려 운영 DB에 아무 기록도 남지 않는지, 결과 CSV가 나오는지 확인한다.

## 3. 전/후 비교

- [ ] 3.1 조건 A(기준 사진 없음)와 조건 B(기준 사진 있음)로 데이터셋 전체를 판정한다.
- [ ] 3.2 A와 B의 결과가 다른 사진은 3번 다시 돌려 결과가 흔들리는지 확인한다.
