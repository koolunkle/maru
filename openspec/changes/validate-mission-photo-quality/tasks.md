## 1. 사진 등록 이후 준비

- [ ] 실제 기준 사진과 제출 사진의 장소·각도·조명·개인정보 여부 및 사용 권한을 확인한다.
- [ ] 현재 Maru DB의 확인된 미션 UUID에 기준 사진을 등록한다. 관리자 페이지의 Maru 연동은 별도 구현 작업이다.

## 2. 검증

- [ ] 같은 장소·다른 장소·다른 조명과 각도·개인정보 사진으로 정확도·지연·비용을 기록한다.
- [ ] 실제 개인정보 탐지부터 비공개 처리·출석·보상까지 확인한다.
- [ ] 실제 제공자 환경의 시간 초과·재시도 동작을 확인한다. 운영 공용 설정은 변경하지 않는다.
- [ ] 실제 사진 제출·판정 결과 화면과 Expo Go 실기기를 확인한다.
- [ ] 검증 기록을 추가하고 임시 계정·사진·관련 데이터를 정리한다.
- [ ] npm run spec:validate, npm run typecheck, npm run lint, npm test를 실행하고 미리보기 URL에서 결과를 확인한다.
