## MODIFIED Requirements

### Requirement: 한 줄 보내기
앱은 마음 보관함 탭의 "마음 우체통"에서 1~60자 한 줄(공백만은 불가)을 써서 보내게 해야 한다(SHALL). 작성 화면에는 글자 수와 "검수를 거친 뒤 다른 사람에게 전달돼요. 이름이나 연락처는 함께 보내지 않아요. 연락처나 만남 제안은 적지 않아요."를 보여 준다.

#### Scenario: 공백만 입력
- **WHEN** 공백만 입력한다
- **THEN** '보내기'를 누를 수 없다

#### Scenario: 시트를 닫았다 열기
- **WHEN** 쓰던 중에 시트를 닫았다가 다시 연다
- **THEN** 쓰던 내용이 남아 있다

#### Scenario: 네트워크 재시도
- **WHEN** 보내기 응답 전에 연결이 끊겨 같은 한 줄을 다시 보낸다
- **THEN** 한 번만 저장된다

#### Scenario: 저장 실패
- **WHEN** 보내기가 실패한다
- **THEN** 입력이 남아 있고 "한 줄을 맡기지 못했어요. 다시 눌러볼까요?"가 보인다

### Requirement: 읽기와 알림
앱은 받은 한 줄을 누르면 본문과 "— 이름 없는 서울의 친구"를 보여 주고 읽음으로 저장해야 한다(SHALL). 우체통 카드에는 안 읽은 개수를 보이고, 마음 보관함에 들어왔을 때 안 읽은 글이 있으면 계정마다 하루(KST) 한 번 수신함을 자동으로 연다.

#### Scenario: 안 읽은 글 표시
- **GIVEN** 안 읽은 한 줄이 2개 있다
- **WHEN** 마음 보관함을 연다
- **THEN** 카드에 "아직 읽지 않은 한 줄 2개가 있어요"가 보이고 그날 처음이면 수신함이 열린다

#### Scenario: 읽음 저장 실패
- **WHEN** 읽음 저장이 실패한다
- **THEN** "읽음 표시를 저장하지 못했어요. 다시 눌러볼까요?"와 '읽음 표시 다시 저장'이 보인다

#### Scenario: 다른 사람의 글 보호
- **WHEN** 제3자가 남의 보낸 글이나 받은 글을 요청한다
- **THEN** 아무것도 돌려받지 못한다
