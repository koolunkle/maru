> 이후: 2026-11-02 `ADMIN_PASSWORD`를 등록했고 운영 `/admin`에서 로그인·미션 CRUD·사진 업로드·삭제를 확인했다(#89). 아래는 등록 전 시점의 기록이다.

사용자는 이메일 계정 대신 공유 비밀번호로 외부에서 접근하는 관리 웹을 선택했다. `/admin` 구현과 서버 배포를 마쳤으며 비밀번호 서버 시크릿 등록을 기다린다. 새 기능 검증이 끝나기 전까지 `add-admin-mission-management`는 진행 중으로 유지한다.

## 배포

- 설정이 없는 배포 함수는 503 `admin_not_configured`로 모든 관리 접근을 차단한다. 외부 미리보기에서 해당 안내를 확인했다.
