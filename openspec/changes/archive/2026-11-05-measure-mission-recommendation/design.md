## Context

`recommend-missions`는 프로필(관심 카테고리·구·하루 시간·난이도), 최근 14일 기록, 시드 36개, 그 구의 이번 주 행사 최대 10개를 AI에 넘기고 오늘 미션 3개와 이번 주 미션 1개를 받는다. 결과를 코드가 다시 검사하고(금칙어·빈 제목이면 버림, 글자 수 자르기, 시간은 하루 가능 시간으로 깎음), 3 + 1을 채우지 못하면 시드 규칙(`_shared/fallback.ts` `pickSeeds`)으로 대체한다.

## Goals / Non-Goals

**Goals:** 같은 가상 사용자에게 AI 추천과 시드 규칙을 돌려 개인화 지표를 비교하고, 발표에 쓸 수치를 남긴다.

**Non-Goals:** 추천 품질의 정답 판정, 프롬프트 개선, 실사용 효과 측정.

## Decisions

### 평가 스크립트

`eval.mjs`는 사진 평가와 같은 방식이다. `recommend-missions/index.ts`를 `tests/helpers/load-source.mjs`로 불러오고 DB(`admin`)만 가짜로 바꾼다. 가짜 DB는 프로필, 빈 최근 기록, 시드(`data/seoul-challenge-2026-2.json`), 그 구의 행사(`events-snapshot.json`)를 돌려주고, `save_recommendation` 호출을 받아 결과만 기록한다. AI 호출은 `_shared/ai.ts`의 실제 `generateJson`을 감싸 원본 응답과 시간을 함께 남긴다. 조건 R은 `generateJson`이 `null`을 돌려주게 해 운영의 대체 경로를 그대로 탄다.

- A(AI): 사용자마다 2회. 두 번째는 같은 사람을 다시 돌렸을 때의 흔들림을 본다.
- R(시드 규칙): 사용자마다 5회. 규칙이 무작위로 섞기 때문이다.

### 가상 사용자 24명

구 6개(관악·종로·마포·노원·강남·강동, 이번 주 행사 1~10건) × 관심사 조합 8종 × 하루 시간 3종(5·15·30분) × 난이도 3종(1~3)에서 겹치지 않게 24명을 고른다(`eval.mjs`의 `Personas`). 모두 온보딩 직후(최근 기록 없음)로 둔다.

### 지표

| 지표 | 정의 |
| --- | --- |
| 사람 사이 겹침(보조) | 서로 다른 두 사용자가 받은 미션 4개 중 같은 미션의 비율(자카드), 모든 쌍의 평균. 같은 미션 = 시드는 같은 id, AI는 공백·문장부호를 뺀 제목이 같음. 다양성을 보여 줄 뿐 맞춤을 보여 주지는 않는다(아래) |
| 다시 돌렸을 때 겹침 | 같은 사용자의 두 실행 사이 겹침(A만) |
| 관심사 일치 | 최종 미션 4개 중 사용자가 고른 카테고리인 비율 |
| 시간 초과 | 오늘 미션 중 소요 시간이 하루 가능 시간보다 긴 비율. A는 코드가 깎기 전 AI 원본으로도 센다 |
| 난이도 범위 위반 | 오늘 미션 난이도 > 사용자+1, 이번 주 미션 난이도 < 사용자+1 |
| 규칙 위반(AI 원본) | 개수(3 + 1), 글자 수, 금칙어, 오늘 미션의 행사 연결, 목록에 없는 행사 id |
| 행사 미션 비율 | 이번 주 미션이 그 구의 이번 주 행사와 연결된 비율 |
| 대체 발생률 | A 실행 중 3 + 1을 채우지 못해 시드 규칙으로 넘어간 비율 |
| 응답 시간 | A의 AI 호출 중앙값·최대 |
| 시드 규칙의 상한 | 사람마다 시드 36개 중 관심사·하루 시간·난이도(오늘 미션 조건)에 모두 맞는 후보 수. 3개 미만이면 규칙으로는 관심사에 맞는 오늘 미션 3개를 채울 수 없다 |

### 읽는 기준(미리 정함)

- 주 지표는 관심사 일치, 조건 준수, 행사 미션 비율, 시드 규칙의 상한이다. 발표 주장("정해진 목록으로는 만들 수 없다")을 뒷받침하려면 A의 관심사 일치와 행사 미션 비율이 R보다 높고, A의 조건 준수가 R과 같거나 높아야 한다.
- A가 관심사 일치는 높아도 조건 위반이 R보다 많으면 "더 맞추지만 규칙을 덜 지킨다"로 기록한다.
- 사람 사이 겹침은 보조 지표다. 가짜 AI로 배선을 확인할 때(실제 실행 전) R의 겹침이 이미 15% 안팎으로 낮게 나왔다. 시드 규칙도 후보를 무작위로 섞기 때문이다. 그래서 겹침이 낮다는 것만으로는 맞춤을 말할 수 없어, 처음 정한 주 지표에서 보조로 내렸다.
- AI 제목은 매번 새로 쓰이므로 제목 비교는 같은 미션을 다른 말로 쓴 경우를 다르게 센다. 그래서 A의 겹침은 실제보다 낮게 나올 수 있다. AI가 시드 제목을 그대로 쓴 비율도 함께 남겨 이를 보완한다.

## Risks / Trade-offs

- 표본이 24명이고 모두 신규 사용자라 최근 기록에 따른 조정은 재지 않는다.
- 행사 후보는 2026-11-03 시점 스냅샷이다. 다른 주에는 행사 수와 종류가 달라진다.
- Gemini가 혼잡하면 경량 모델이 함께 답한다(운영과 같은 조건). 503이 이어지면 시간을 두고 다시 돌린다.
