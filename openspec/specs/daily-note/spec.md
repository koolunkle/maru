# daily-note Specification

## Purpose
기능 ID F15. 하루 한 번 기분 5단계와 한 줄을 남기는 개인 기록. 본인만 읽고, 주간 리포트(F13)를 만들 때만 AI에 보낸다.

## Requirements

### Requirement: 오늘 한 줄
앱은 휴게소 마음 보관함의 한 줄 기록 시트에서 KST 하루에 기록 하나(기분 5단계 필수, 한 줄 선택 60자 이하)를 저장·수정·삭제하게 해야 한다(SHALL). 기분은 1~5 순서로 "마음이 가벼워요", "조금 가벼워요", "보통이에요", "조금 무거워요", "마음이 무거워요"다.

#### Scenario: 저장
- **WHEN** 기분을 고르고 '저장하기'를 누른다
- **THEN** "오늘의 기록을 저장했어요."가 보인다

#### Scenario: 기분 없이 저장
- **WHEN** 기분을 고르지 않았다
- **THEN** '저장하기'를 누를 수 없다

#### Scenario: 같은 날 다시 저장
- **GIVEN** 오늘 기록이 있다
- **WHEN** 한 줄을 고쳐 저장한다
- **THEN** 오늘 기록 하나가 고친 내용으로 바뀐다

#### Scenario: 삭제 확인
- **WHEN** '오늘 기록 삭제'를 누른다
- **THEN** 바로 지우지 않고 '기록 삭제'·'취소'로 한 번 더 묻는다

### Requirement: 작성 중인 입력 보존
앱은 시트를 닫았다 열거나 저장이 실패해도 작성 중인 입력을 이 기기에 남겨야 한다(SHALL). 쓰는 동안 날짜가 바뀌면 덮어쓰지 않고 안내한다.

#### Scenario: 저장 실패
- **WHEN** 저장이 실패한다
- **THEN** 입력이 남아 있고 "기록을 저장하지 못했어요. 다시 눌러 볼까요?"가 보인다

#### Scenario: 자정을 넘김
- **WHEN** 어제 쓰기 시작한 기록을 자정이 지나 저장한다
- **THEN** "날짜가 바뀌었어요. 작성 중인 내용을 복사한 뒤 오늘 기록을 다시 불러와 주세요."가 보이고 '오늘 기록 다시 불러오기'를 누를 수 있다

### Requirement: 본인만 읽기
앱은 한 줄 기록을 작성자 본인만 읽게 해야 하고, 주간 리포트 생성을 사용자가 고를 때만 AI에 보내야 한다(MUST). 자동 삭제는 하지 않는다.

#### Scenario: 다른 사용자
- **WHEN** 다른 계정이 내 한 줄 기록을 요청한다
- **THEN** 아무것도 돌려받지 못한다
