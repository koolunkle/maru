# onboarding Specification

## Purpose
기능 ID F1. 가입 없이 익명으로 시작하고, 질문 세 개로 추천에 쓸 관심사·동네·하루 시간을 받는다. 설정에서 이 값과 닉네임을 바꾼다.

## Requirements

### Requirement: 익명 시작
앱은 시작 화면(S1)에서 '시작하기'를 누르면 이메일·전화번호 없이 익명 계정을 만들어야 한다(SHALL). 계정은 그 브라우저·기기에만 남는다.

#### Scenario: 처음 시작
- **WHEN** 처음 온 사용자가 S1에서 '시작하기'를 누른다
- **THEN** 익명 계정이 만들어지고 온보딩(S2)으로 이동한다

#### Scenario: 시작 화면 소개 문구
- **WHEN** S1이 보인다
- **THEN** "Maru · 하루 5분, 서울에서 해보는 작은 루틴"이 보인다

### Requirement: 자동 닉네임
앱은 새 계정에 `{형용사} {동물}` 형식의 닉네임(예: "느긋한 수달")을 자동으로 붙여야 한다(SHALL). 중복을 허용한다. 닉네임은 설정에 표시만 하고 앱에서 바꾸는 화면은 없다.

#### Scenario: 닉네임 생성
- **WHEN** 익명 계정이 만들어진다
- **THEN** 형용사와 동물 목록에서 무작위로 고른 닉네임이 붙고 설정(S9)에 표시된다

### Requirement: 온보딩 세 질문
앱은 온보딩에서 관심 카테고리(1~3개), 생활권(서울 25개 구 중 1개), 하루 가능 시간(5·15·30분 중 1개)을 차례로 받아야 한다(SHALL). 카테고리는 산책·운동, 요리·식사, 문화·전시, 자기계발, 동네 탐방, 생활 리듬, 사람 만나기 7종이다.

#### Scenario: 카테고리 상한
- **WHEN** 카테고리 3개를 고른 상태에서 네 번째를 누른다
- **THEN** 네 번째는 선택되지 않는다

#### Scenario: 온보딩 완료
- **WHEN** 세 질문에 답하고 완료한다
- **THEN** 홈(S3)으로 이동하고 오늘의 미션 카드가 보인다

#### Scenario: 추천을 만들 수 없을 때
- **WHEN** 온보딩을 마쳤지만 AI 추천이 실패한다
- **THEN** 홈에는 365 서울챌린지 시드에서 고른 미션이 보인다

### Requirement: 설정에서 다시 고르기
앱은 설정(S9)에서 관심 카테고리, 구, 하루 가능 시간을 온보딩과 같은 제약으로 바꿀 수 있게 해야 한다(SHALL). 설정은 홈 오른쪽 위 버튼으로 연다. 설정 하단에는 데이터·글꼴·음원 출처를 표시한다.

#### Scenario: 구 변경
- **WHEN** 설정에서 구를 종로구로 바꾼다
- **THEN** 다음 추천부터 종로구 기준으로 만든다

#### Scenario: 출처 표시
- **WHEN** 설정 화면 하단을 본다
- **THEN** 365 서울챌린지, 서울 열린데이터광장, Pretendard(OFL), 배경음 음원 출처가 보인다
