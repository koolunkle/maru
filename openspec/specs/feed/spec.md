# feed Specification

## Purpose
기능 ID F6. 공개를 고른 인증을 익명 피드(S6)에 모아 보여 주고, 빠른 반응과 검수를 거친 익명 댓글로 가볍게 응원을 주고받는다.

## Requirements

### Requirement: 공개 인증 피드
앱은 공개를 고르고 통과한 인증만 최신순으로 20개씩 피드에 보여 줘야 한다(SHALL). 게시물에는 사진, 미션 제목, 작성자 닉네임, 소감이 보인다. 비공개 인증과 비공개 저장 판정 인증은 보이지 않는다.

#### Scenario: 이어 불러오기
- **GIVEN** 공개 인증이 25개 있다
- **WHEN** 피드 끝까지 내린다
- **THEN** 처음 20개 뒤에 나머지 5개가 이어서 보인다

#### Scenario: 비공개 인증
- **WHEN** 공개를 끄고 인증했다
- **THEN** 그 인증은 피드에 보이지 않는다

### Requirement: 빠른 반응
앱은 게시물마다 "응원해요", "나도 해볼래요", "멋져요" 세 가지 반응을 검수 없이 바로 반영해야 한다(SHALL). 한 사용자는 게시물마다 각 반응을 한 번씩만 누를 수 있고, 다시 누르면 취소된다.

#### Scenario: 반응 누르기
- **WHEN** 게시물에서 "응원해요"를 누른다
- **THEN** 응원해요 수가 1 늘고 눌린 상태로 보인다

#### Scenario: 반응 실패
- **WHEN** 반응 저장이 실패한다
- **THEN** 반응 수와 눌림 상태는 그대로이고 "지금은 반응을 남기지 못했어요. 다시 눌러 볼까요?"가 보인다

### Requirement: 익명 댓글
앱은 공개 게시물에 1~200자 익명 댓글을 쓰게 하고, content-moderation 규칙으로 검수해 승인된 댓글만 시간차로 공개해야 한다(SHALL). 같은 댓글을 네트워크 재시도로 다시 보내도 한 번만 저장된다.

#### Scenario: 댓글 작성
- **WHEN** 댓글을 쓰고 보낸다
- **THEN** 작성자에게 "약 3시간 뒤 공개돼요"(시연 모드는 "약 1분 뒤 공개돼요")가 보이고, 다른 사람에게는 공개 시각 뒤에 보인다

#### Scenario: 거절된 댓글
- **WHEN** 댓글이 거절되거나 위기로 분류된다
- **THEN** 작성자에게 "이 댓글은 공개되지 않았어요"가 보이고, 위기면 도움 안내 카드도 보인다
