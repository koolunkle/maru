# photo-verification Specification

## Purpose
기능 ID F4. 진행 중인 미션을 사진 한 장과 선택 소감으로 인증하고, AI가 바로 통과·다시 찍기·비공개 저장을 판정한다. 통과하면 완료·출석·가구 보상이 한 번에 처리된다.

## Requirements

### Requirement: 인증 입력
앱은 인증 화면(S5)에서 사진 1장(필수), 소감(선택, 100자 이하), 피드 공개 여부(기본 비공개)를 받아야 한다(SHALL). 사진은 카메라로 찍거나 앨범에서 고를 수 있다.

#### Scenario: 사진 없이 제출
- **WHEN** 사진을 고르지 않았다
- **THEN** 제출 버튼을 누를 수 없다

#### Scenario: 카메라 권한 거부
- **WHEN** 카메라 권한을 거부했다
- **THEN** "카메라 권한이 필요해요"가 보이고 앨범에서 고를 수 있다

### Requirement: 업로드 전 사진 처리
앱은 사진을 올리기 전에 긴 변 1024px JPEG로 다시 인코딩해야 한다(SHALL). 그래서 촬영 시각·위치 같은 EXIF 정보는 서버에 올라가지 않는다.

#### Scenario: 큰 원본
- **WHEN** 4000px 사진을 고른다
- **THEN** 긴 변 1024px JPEG로 올라가고 EXIF가 남지 않는다

### Requirement: AI 판정
앱은 사진이 미션 인증 힌트와 맞는지 AI로 판정해 세 결과 중 하나를 보여 줘야 한다(SHALL). 판정 한 줄은 40자 이하다.
- 다시 찍기(retry): 직접 찍지 않은 사진(만화·일러스트·게임·방송 장면·화면 캡처·내려받은 이미지), 빈 화면, 미션과 무관한 사진. 관련 있어 보여도 직접 찍지 않았으면 다시 찍기다.
- 통과(pass): 직접 찍은 사진이 힌트와 관련 있다. 애매하면 통과다.
- 비공개 저장(privacy): 얼굴 정면, 차량 번호판, 주소·전화번호가 보인다. 완료로 인정하되 피드에 공개하지 않는다.

#### Scenario: 통과
- **WHEN** 힌트가 "하늘이 보이는 사진"인 미션에 직접 찍은 하늘 사진을 낸다
- **THEN** 미션이 완료되고 해낸 것을 짚는 한 줄이 보인다

#### Scenario: 화면 캡처
- **WHEN** 인터넷에서 받은 하늘 이미지를 낸다
- **THEN** 미션은 진행 중으로 남고 무엇이 안 보이는지 알려 주며, 횟수 제한 없이 다시 낼 수 있다

#### Scenario: 얼굴이 보이는 사진
- **WHEN** 공개를 켜고 낸 사진에 다른 사람 얼굴 정면이 보인다
- **THEN** 미션은 완료되고 공개는 꺼지며 비공개로 저장했다는 안내가 보인다

#### Scenario: AI가 판정 한 줄을 쓰지 못할 때
- **WHEN** 판정은 났지만 쓸 수 있는 한 줄이 없다
- **THEN** 결과별 기본 문구를 보여 준다: 통과 "오늘의 미션을 해냈어요", 다시 찍기 "미션이 잘 안 보여요. 다시 찍어볼까요?", 비공개 저장 "얼굴이나 개인정보가 보여서 비공개로 저장했어요"

### Requirement: 완료와 보상을 한 번에 처리
앱은 통과·비공개 저장 판정이 나면 미션 완료, 출석·연속 출석, 가구 지급을 한 번에 처리해야 한다(SHALL). 같은 인증을 다시 요청해도 결과와 보상은 한 번만 생긴다.

#### Scenario: 네트워크 재시도
- **WHEN** 판정 응답을 받기 전에 연결이 끊겨 같은 인증을 다시 요청한다
- **THEN** 처음 판정 결과가 돌아오고 가구는 한 번만 지급된다

### Requirement: AI를 쓸 수 없을 때
앱은 AI 판정이 실패하거나 20초 안에 오지 않으면 운영 설정에 따라 통과로 처리하거나 재시도를 안내해야 한다(SHALL). 지금 운영 설정은 통과다. 대체 판정은 AI 판정처럼 표시하지 않는다.

#### Scenario: 통과 설정
- **GIVEN** 대체 설정이 통과다
- **WHEN** AI가 응답하지 않는다
- **THEN** 미션이 완료되고 판정 한 줄은 AI 카드 모양이 아니다

#### Scenario: 재시도 설정
- **GIVEN** 대체 설정이 나중에 다시다
- **WHEN** AI가 응답하지 않는다
- **THEN** 미션은 진행 중으로 돌아가고 "확인이 늦어지고 있어요. 잠시 뒤 다시 눌러 주세요."가 보인다

### Requirement: 기준 사진을 이용한 인증
앱은 기준 사진이 등록된 미션에서 해당 미션의 기준 사진을 제출 사진과 비교해 기존 인증 판정의 근거로 사용해야 한다(SHALL). 기준 사진이 없는 미션은 기존 인증을 유지한다. 장소 일치가 불확실하면 기존의 관대한 판정 기준을 따르고, 개인정보와 직접 촬영 여부의 기존 규칙을 유지한다.

#### Scenario: 기준 사진이 있는 미션
- **WHEN** 사용자가 기준 사진이 등록된 미션의 사진을 제출한다
- **THEN** 해당 미션의 기준 사진만 비교에 사용하고 기존 통과·다시 찍기·비공개 저장 결과를 제공한다

#### Scenario: 기준 사진이 없는 미션
- **WHEN** 사용자가 기준 사진이 없는 미션을 인증한다
- **THEN** 기존 사진 인증 방식으로 판정한다

#### Scenario: 장소가 불확실한 사진
- **WHEN** 직접 찍은 사진의 장소 일치 여부가 불확실하다
- **THEN** 기존의 애매하면 통과하는 기준과 개인정보 판정 규칙을 따른다

#### Scenario: 기준 사진을 불러올 수 없음
- **WHEN** 등록된 기준 사진 하나라도 불러올 수 없다
- **THEN** 불완전한 기준 사진으로 비교하지 않고 기준 사진이 없는 미션처럼 AI가 판정한다
- **AND** 직접 촬영 여부와 개인정보 판정을 건너뛰지 않는다

#### Scenario: AI를 사용할 수 없음
- **WHEN** AI 판정이 실패하거나 제한 시간 안에 응답하지 않는다
- **THEN** 기존 운영 설정에 따라 통과하거나 재시도를 안내한다
