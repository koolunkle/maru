# room-rewards Specification

## Purpose
기능 ID F7. 미션 기록으로 가구 6종을 받아 일러스트 방(S8)에 놓는다. 방에는 시간과 기록이 남고, 도감으로 앞으로 받을 가구를 보며, 벽지·바닥을 고른다. 포인트나 현금성 보상은 없다.

## Requirements

### Requirement: 가구 획득 조건
앱은 미션을 완료할 때 아래 조건을 처음 만족한 가구를 지급해야 한다(SHALL). 같은 가구는 하나만 가진다.

| 가구 | 놓는 자리 | 조건 |
| --- | --- | --- |
| 화분 | 창가 | 첫 미션 완료 |
| 스탠드 | 책상 | 연속 출석 3일 |
| 소파 | 바닥 | 연속 출석 7일 |
| 운동화 선반 | 바닥 | 산책·운동 미션 5회 완료 |
| 벽시계 | 벽 | 첫 이번 주 미션 완료 |
| 전시 포스터 | 벽 | 문화행사 미션 1회 완료 |

#### Scenario: 첫 미션
- **WHEN** 처음으로 미션을 완료한다
- **THEN** 화분을 받는다

#### Scenario: 행사 미션 하나로 두 가구
- **GIVEN** 이번 주 미션을 완료한 적이 없다
- **WHEN** 행사 연계 이번 주 미션을 완료한다
- **THEN** 벽시계와 전시 포스터를 함께 받는다

### Requirement: 가구 받는 순간
앱은 가구를 받으면 인증 결과 화면에서 상자가 열리며 가구가 나오는 장면을 한 번 보여 주고, "방에 놓기"로 내 방의 맞는 빈 자리에 바로 놓게 해야 한다(SHALL). 동작 줄이기 설정이면 움직임 없이 보여 준다.

#### Scenario: 방에 놓기
- **WHEN** 스탠드를 받고 "방에 놓기"를 누른다
- **THEN** 내 방으로 이동하고 비어 있는 책상 자리에 스탠드가 놓인다

#### Scenario: 빈 자리 없음
- **WHEN** 맞는 자리가 모두 차 있다
- **THEN** 꾸미기 화면이 열려 놓을 자리를 고르게 한다

### Requirement: 보기와 꾸미기
앱은 평소에는 방만 보여 주고, "꾸미기"에서만 자리 6개(벽 2, 창가, 책상, 바닥 2)를 표시해야 한다(SHALL). 자리를 눌러 그 자리 종류의 가구를 놓거나, 같은 종류의 다른 자리로 옮긴다. 옮길 자리에 가구가 있으면 서로 바꾼다. 끌어서 옮기기는 없다.

#### Scenario: 맞지 않는 자리
- **WHEN** 바닥 자리를 누른다
- **THEN** 바닥에 놓는 가구만 고를 수 있다

#### Scenario: 놓을 가구가 없는 자리
- **WHEN** 가진 가구 중 그 자리에 맞는 것이 없다
- **THEN** "이 자리에 놓을 수 있는 가구가 아직 없어요. 도감에서 받는 방법을 볼 수 있어요."가 보인다

### Requirement: 시간과 기록이 남는 방
앱은 방에 지금 시간과 사용자 기록을 반영해야 한다(SHALL).
- 창밖 하늘은 KST 아침(5~10시)·낮(10~17시)·저녁(17~19시)·밤으로 바뀌고, 저녁·밤에는 방이 어두워지며 스탠드가 있으면 불빛이 퍼진다.
- 벽시계는 지금 시각을 가리킨다.
- 화분은 연속 출석에 따라 새싹(3일 미만) → 잎(7일 미만) → 꽃(7일 이상)으로 자란다.
- 전시 포스터에는 마지막으로 완료한 행사 미션의 행사 이름이 적힌다.

#### Scenario: 밤에 스탠드
- **GIVEN** 스탠드를 놓았다
- **WHEN** 밤 10시(KST)에 방을 연다
- **THEN** 창밖이 밤하늘이고 스탠드 불빛이 퍼진다

### Requirement: 가구 도감
앱은 도감에 모든 가구를 보여 줘야 한다(SHALL). 가진 가구는 그림·받은 날·"방에 있어요"(놓은 경우)를, 없는 가구는 실루엣·획득 조건·남은 횟수(예: "2번 더 하면 받아요")를 보이고, 위에 모은 비율을 표시한다.

#### Scenario: 남은 횟수
- **GIVEN** 산책·운동 미션을 3번 완료했다
- **WHEN** 도감을 연다
- **THEN** 운동화 선반은 실루엣과 "2번 더 하면 받아요"로 보인다

### Requirement: 벽지와 바닥
앱은 꾸미기에서 벽지 5종과 바닥 4종을 고르게 해야 한다(SHALL). 잠금은 미션 기록으로 풀리고, 고른 값은 이 기기에만 저장된다(다른 기기에서는 기본 벽·원목).

| 종류 | 이름 | 잠금 해제 |
| --- | --- | --- |
| 벽지 | 기본 벽 | 처음부터 |
| 벽지 | 세로 줄무늬 | 산책·운동 3회 완료 |
| 벽지 | 물방울 | 연속 출석 5일 |
| 벽지 | 체크 | 문화·전시 2회 완료 |
| 벽지 | 민트 | 이번 주 미션 2회 완료 |
| 바닥 | 원목 | 처음부터 |
| 바닥 | 헤링본 | 요리·식사 2회 완료 |
| 바닥 | 타일 | 동네 탐방 2회 완료 |
| 바닥 | 카펫 | 사람 만나기 2회 완료 |

#### Scenario: 잠긴 벽지
- **GIVEN** 산책·운동 미션을 1번 완료했다
- **WHEN** 세로 줄무늬 벽지를 고르려 한다
- **THEN** 고를 수 없고 잠금 해제 조건이 보인다

#### Scenario: 기기 저장 값이 없을 때
- **WHEN** 체크 벽지를 고른 뒤 이 기기의 앱 저장 데이터가 지워진다
- **THEN** 가구 배치는 그대로이고 벽지·바닥은 기본 벽·원목으로 보인다
