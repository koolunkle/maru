# 미션 관리

배포한 웹 주소 뒤에 `/admin`을 붙여 접속하고 관리자 비밀번호를 입력한다. 앱 계정이나 이메일은 필요 없다. 현재 Maru 프로젝트 `jpipzrmspryzvjykxefm`의 공용 미션을 관리하므로 저장 즉시 실제 추천에 영향을 준다. 사용자별 AI 미션은 관리 목록에서 제외한다.

1. 제목으로 검색하고 미션을 선택하거나 **새 미션 작성**을 누른다.
2. 제목·카테고리·난이도·분 단위 시간·인증 힌트를 입력해 저장한다. 추천 기간은 한국 시간으로 양 끝 날짜를 포함하고 비우면 해당 방향으로 제한하지 않는다.
3. 저장한 미션에 기준 사진과 비교 힌트를 등록한다. 미션당 최대 4장, 각 2 MiB 이하 JPEG·PNG·WebP다. 직접 촬영한 장소 사진을 사용하고 개인정보가 담긴 사진은 피한다.
4. 사진을 등록한 뒤 해당 미션 인증으로 비교를 확인한다. 같은 장소의 다른 각도·조명과 다른 장소 사진을 통한 정확도 검증은 별도로 진행한다.

기존 사용자 활동이나 기준 사진이 연결된 미션은 삭제할 수 없다. 사진은 개별 삭제할 수 있다. 저장소 오류 시 성공으로 표시하지 않으며, 사진 정리 안내가 나오면 목록을 다시 불러와 삭제를 재시도한다. 업로드 도중 연결 오류가 생기면 새 파일만 정리한다. 정리까지 실패하면 서버 로그의 `admin photo cleanup required` 경로를 운영자가 확인한다.

비밀번호는 화면 메모리에만 남고 새로고침·관리 종료 후 다시 입력한다. 공유 비밀번호를 아는 사람은 모두 같은 권한을 가지며 개인별 감사 이력은 제공하지 않는다. 틀린 입력이 주소별 5회 또는 전체 100회에 도달하면 10분 동안 접근이 제한된다. 비밀번호를 URL·채팅·PR에 적지 않는다.

## 운영자 설정

관리 비밀번호를 앱 `.env.local`이나 `EXPO_PUBLIC_*`에 넣지 않는다. 최초 준비 시 생성한 `.env.admin.local`은 Git 제외 파일이며 서버 시크릿 등록용이다. 이 파일은 DB 비밀번호나 Supabase 서버 키를 담지 않는다. 파일을 안전한 비밀번호 관리자로 옮기고 보관한다.

승인된 마이그레이션 적용 후 서버 시크릿과 함수만 설정한다. 비밀번호를 바꾸려면 로컬 비밀 파일을 수정하고 같은 명령을 실행한다. 변경 시 입력 제한 키도 새로 시작한다.

```bash
npx supabase secrets set --env-file .env.admin.local --project-ref jpipzrmspryzvjykxefm
npx supabase functions deploy admin-missions --project-ref jpipzrmspryzvjykxefm --no-verify-jwt
```

`--no-verify-jwt`는 자체 비밀번호 검사가 있는 이 함수에만 사용한다. 기존 사용자 함수는 JWT 검증을 유지한다. 웹은 CONTRIBUTING.md 절차대로 미리보기 배포하며 운영 웹 배포와 PR 병합은 별도다.
