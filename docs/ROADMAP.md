- 순서는 [USER-FLOWS.md](./USER-FLOWS.md)의 흐름(시작·온보딩 → 홈 → 미션 상세 → 인증 → 릴레이 → 피드 → 내 방 → 기록·리포트 → 우체통 → 한 줄 기록 → 타임캡슐 → 설정).
- 기능마다 같은 기준으로 본다: 동작(정상·빈 상태·오류·재시도), 입력 보존, 휴대폰 폭·다크 모드·키보드, 접근성 이름·터치 영역, 문구 규칙(PRD §7).
- 찾은 문제는 GitHub Issue로 남기고(`막힘`/`불편`/`다듬기`), 문제 하나에 PR 하나로 고친다.
- 알려진 항목: 한 줄 기록·타임캡슐 시트를 닫으면 저장하지 않은 입력이 사라진다(마음 우체통은 유지).
