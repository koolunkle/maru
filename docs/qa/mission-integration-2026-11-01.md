| AI 시간 제한 | Gemini 응답을 중단한 모의 테스트에서 제한을 20ms로 축소 | null 반환으로 대체 경로에 전달 |

후보 부족 화면 검증은 운영 공용 미션의 기간이나 가용성을 바꾸지 않았다. 장애 대체 API 점검의 합성 파일은 AI 사진 품질 측정용 사진이 아니다. retry·privacy 트랜잭션 검증은 AI가 실제 개인정보를 탐지했음을 증명하지 않는다.
